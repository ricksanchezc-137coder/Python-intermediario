## Módulo 1 — Funções como cidadão de primeira classe (closures)

Estudo de funções como objetos de primeira classe e closures em Python: funções aninhadas, `nonlocal`, e compartilhamento de estado entre closures.

**Exercícios:**
- `criar_multiplicador(fator)` — closure simples com valor fixo
- `criar_conta(saldo_inicial)` — duas closures (`depositar`, `consultar_saldo`) compartilhando o mesmo estado
- `criar_cache(func)` — memoização manual usando dict guardado na closure (base conceitual do `functools.lru_cache`, visto no Módulo 4)
