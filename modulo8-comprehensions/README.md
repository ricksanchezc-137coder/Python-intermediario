## Módulo 8 — Comprehensions avançadas

Pasta: `modulo8-comprehensions/`

Praticado: list/dict/set/generator comprehension, comprehensions aninhadas (achatamento de listas de listas), expressões condicionais (`if/else`) vs. filtro (`if`), e a combinação dos dois. Exercício final combina comprehension aninhada + dict comprehension com filtro para extrair palavras de uma lista de frases e mapeá-las ao seu tamanho.

**Principais arquivos:** `dict_comp.py`, `set_comp.py`, `generator_comp.py`, `comp_aninhada.py`, `expressao_cond.py`, `exercicio_final.py`
